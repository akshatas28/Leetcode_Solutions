## What is this?

This repository contains my **LeetCode problem-solving practice** using Java and Python.

The focus is on understanding the problem, identifying the right pattern, writing a clean solution, and analyzing its efficiency.

```text
Problem
   ↓
Understand constraints
   ↓
Find the pattern
   ↓
Choose the data structure
   ↓
Implement
   ↓
Test edge cases
   ↓
Analyze complexity
```

## How I Approach a Problem

### 1. Understand

Read the problem carefully and identify what is actually required.

### 2. Constraints

Look at input size and constraints before choosing an approach.

### 3. Pattern

Ask whether the problem matches a known DSA pattern.

### 4. Implementation

Write a clear solution and handle important edge cases.

### 5. Complexity

Analyze:

```text
Time Complexity
Space Complexity
```

### 6. Improve

If a better approach exists, compare it with the original solution.

## Complexity Reference

| Complexity | Typical use                     |
| ---------- | ------------------------------- |
| O(1)       | Direct access / constant work   |
| O(log n)   | Binary search                   |
| O(n)       | Single traversal                |
| O(n log n) | Efficient sorting               |
| O(n²)      | Pair comparisons / nested loops |

The goal is to understand **why** a solution has a particular complexity, not just to write the notation.
